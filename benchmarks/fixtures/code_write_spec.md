# Spec: pair arithmetic module

Implement a module with exactly these public functions:
- `add_pair(a, b)`: return a + b.
- `scale_pair(a, b, factor)`: return (a * factor, b * factor).
- `pair_total(pair)`: return pair[0] + pair[1].

No other public functions are required. Follow the reference style: small functions, no classes.
